Support

Help for library staff.

Contact details will be published here when support channels are available.

Installation help

Use the official Windows installer. If Windows warns about an unfamiliar newly published application, verify the download source and installer name first.

Login problems

Confirm the username, password and account status with an Administrator. Passwords cannot be recovered from the application; an Administrator can reset them.

Backup problems

Confirm the backup location is accessible and has sufficient free storage. Never replace the database manually while the application is running.

Update problems

Updates are optional. Check that an internet connection is available, then choose Settings → Check for Updates.
