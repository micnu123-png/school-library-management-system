Documentation

Install safely. Keep data protected.

School Library Management System is designed to work locally, even without day-to-day internet access.

System Requirements

Windows 10 or Windows 11, 64-bit; 4 GB RAM recommended; at least 500 MB available disk space. Internet is only needed for download and optional update checks.

Installation

Download SchoolLibrarySystem_Setup_v2.00.exe from the official release. Run the installer, follow the wizard, and create the first Administrator account on first launch.

Data Location

Application data: %LOCALAPPDATA%\SchoolLibrarySystem
Database: %LOCALAPPDATA%\SchoolLibrarySystem\data\lms.db

Backups

Local backups are stored in %LOCALAPPDATA%\SchoolLibrarySystem\data\backups.

Upgrade Safety

Upgrades are designed to preserve local user data. Where configured by the installer, a backup is created before an upgrade proceeds.

Uninstallation

Uninstalling removes the installed program and shortcuts. It preserves local user data so it remains available after reinstalling.
