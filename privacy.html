Privacy

Local-first by design.

Library data

Library records are stored locally by the desktop application using SQLite. The public website does not connect to, receive, or expose a school’s local library database.

Backups and passwords

Backups are stored locally. Passwords are stored as secure hashes and are not stored in plaintext.

Internet use

Normal library operations do not require an internet connection. When configured, the update checker may connect to the official CatholicDiscovery Digital release manifest to check for a newer application version.

Website

This static website is for information, downloads, documentation and release notes. Do not submit private school information through public support links unless an official support process is published.
