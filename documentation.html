Documentation

Get started with confidence.

1. Download and installation

Download the Windows installer from the official site and run it. Normal operations do not require an internet connection.

2. First launch

Create the first Administrator account. There is no default username or password. Sign in with an active account on later launches.

3. Dashboard

Use the dashboard to review student, book, borrowing, overdue, reservation and fine summaries.

4. Students and books

Add students using a unique Student ID. Add books with a unique Book ID, quantity and optional PDF attachment. Use search to find records quickly.

5. Borrowing and returns

Select a student and an available book, then set the borrowing period. Return the selected loan to restore availability and calculate any overdue fine.

6. Reservations and reports

Create reservations for students, mark them fulfilled or cancelled, and use Reports for inventory, overdue and borrowing information.

7. Users and backups

Administrators manage user accounts and permissions. Create backups regularly; restore creates a safety backup before changing the live database.

8. Updating and troubleshooting

Select Settings → Check for Updates. Automatic checks are non-blocking. If offline, continue working normally and try again later. For login or backup problems, see Support.
