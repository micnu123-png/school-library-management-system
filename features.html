Product features

Everything a school library needs.

Professional desktop tools for everyday library administration.

Book Management

Book ID, title, author, category, ISBN, quantity, condition, PDF attachments and QR codes.

Student Management

Student ID, name, class, phone and email records with search and CSV workflows.

Borrow & Return

Due dates, availability, returns and consistent fine calculation.

Reservations

Active reservations, fulfilment and cancellation tracking.

Reports

Borrowing, overdue items, inventory, fines, reservations and library activity.

Authentication

Administrator, Librarian and Assistant roles with secure password hashing.

User Management

Administrators can create users, change roles, reset passwords and manage activation.

Backup & Restore

Automatic and manual local backups with a protected restore workflow.

Modern Interface

A CustomTkinter-based Windows interface with System, Light and Dark themes.
